# Casa do Português: level pages (standalone)

23 static pages, one per theme card (Sala de Aulas 9, Biblioteca 6, Cozinha 4, Jardins 4). Each page has the level buttons A1, A2, B1, B2, C1/C2 that open the Google Drive folders. 100 Histórias has two sets of buttons (Lendas e Milagres, Mulheres).
The room pages (cards for each theme) are built by Alessandra on casadoportugues.eu and link to these pages.

- Open `sala-de-aulas/healthcare/index.html` (or any other theme page) in a browser to preview.
- Level links to Google Drive: `rooms/links.js` (120 links, filled 2 Nov 2026).
- Illustrations: final Bonte Raaf set. Pages are noindex. Not connected to casadoportugues.eu yet.
